# 📚 Library Management System in Java

## 📌 Overview

The **Library Management System** is a Java-based project developed to understand and practice the fundamental concepts of Object-Oriented Programming (OOP).

The project simulates a basic library environment where different types of users can interact with library resources. It focuses on writing structured, reusable, and maintainable code using core Java concepts.

## 🎯 Objectives

- Understand and implement the four pillars of OOP.
- Practice classes, objects, constructors, and methods.
- Learn how inheritance and abstraction help organize code.
- Implement encapsulation to protect data.
- Explore polymorphism through method overriding.
- Improve Java programming and object-oriented design skills.

## 🛠️ Technologies Used

- **Language:** Java
- **Core Concepts:** Object-Oriented Programming (OOP)
- **IDE:** IntelliJ IDEA / Eclipse / VS Code

## 🧠 OOP Concepts Implemented

### 1. Encapsulation

Uses private data members and controlled access through methods to protect an object's internal state.

### 2. Inheritance

Allows specialized classes to inherit common properties and behaviors from parent classes, reducing code duplication.

### 3. Abstraction

Uses abstract classes and methods to define common structures while leaving specific implementations to subclasses.

### 4. Polymorphism

Demonstrates how method overriding allows subclasses to provide their own implementations of inherited methods.

### 5. Constructors

Uses default, parameterized, and copy constructors to initialize objects in different ways.

### 6. Static Members

Uses static variables and methods to manage class-level data and shared functionality, where appropriate.

## 🚀 Getting Started

### Prerequisites

- Java Development Kit (JDK) installed.
- A Java-compatible IDE or code editor.
- Basic understanding of Java syntax.

### Installation and Execution

1. Clone the repository:

   ```bash
   git clone <YOUR_REPOSITORY_URL>
   ```

2. Navigate to the project directory:

   ```bash
   cd <YOUR_PROJECT_DIRECTORY>
   ```

3. Open the project in your preferred Java IDE.

4. Locate the main class containing the `main()` method.

5. Compile and run the application.

   If your project uses a standalone Java file, you can run it using:

   ```bash
   javac Main.java
   java Main
   ```

   Replace `Main.java` with the appropriate filename if needed.
